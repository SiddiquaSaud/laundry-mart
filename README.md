# Laundry Mart

## Project Description
This project is a simple HTML website created for the TuteDude HTML assignment. It represents a  Laundry Mart webpage.

## Features
- Welcome Header
- About Section
- Laundry Image
- Services Section
- Price List
- Book Now Form
- Contact Information

## Technologies Used
- HTML5

## How to Run
1. Download the project files.
2. Open the `index.html` file in any web browser.
